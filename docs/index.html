fixBib

GitHub

Clean, verify, and format your BibTeX references for prescribed publication styles.

Upload a .bib file or paste directly from Overleaf. fixBib verifies every entry by DOI or title against CrossRef, Semantic Scholar, and OpenAlex. Select your target publication format (such as AIAA Journal, Journal of Fluid Mechanics, or Physics of Fluids), and fixBib automatically formats publication titles (Title Case vs. Sentence Case), journal names (full titles vs. standard ISO abbreviations), AIAA paper entries (as @misc or @inproceedings with note), preserves full author names, and exports clean, standardized BibTeX. Everything runs 100% in-browser — your data never leaves your machine (unless you choose to export it).

How it works

1

Upload or paste

Drop your .bib file or paste directly from Overleaf. Everything is parsed in your browser — nothing is uploaded to any server.

2

Waterfall verification & caching

Each entry is verified via an intelligent API waterfall (CrossRef → Semantic Scholar → OpenAlex). Standardized fields are cached locally in your browser so repeat runs execute instantaneously without hitting API rate limits.

3

Review & edit

Results are color-coded: Verified means everything matches, Auto-Updated shows a diff you can accept or edit inline, and Needs Review flags possible errors. A live preview shows the corrected BibTeX in real time.

4

Download

Download or copy your corrected .bib file formatted in your chosen publication style with all custom settings applied. Ready for Overleaf or LaTeX.

Features

API Waterfall & Local Caching

Verifies entries using a fast CrossRef → Semantic Scholar → OpenAlex waterfall. Caches only essential fields in local storage to eliminate redundant API calls and prevent rate limits.

Clean & Beautify

Aligns field operators, strips junk tags, fixes casing, and groups fields logically.

Citation Key Generator

Toggles unified citation keys formatted by author name, year, and key title words (e.g. roy2025direct).

Publication Formats & Custom Styling

Flexible formatting for preset journal styles (AIAA Journal, JFM, PoF) or configure Custom formatting for Publication Title casing (Sentence vs. Title Case) and Journal Name (Full Form vs. ISO 4 Abbreviations).
